# AIGC pricing

AI 视频生成平台统一度量衡。比较相同底模、生成条件和规格下，各平台套餐的每秒成本与可生成时长。

本仓库只发布可部署网页和脱敏数据，不包含采集工具、平台账户、登录环境、原始接口请求或本地研究档案。

## 在线查看

GitHub Pages 配置完成后： https://ydd0503.github.io/aigc-pricing/

## 在其他电脑查看

下载本仓库 ZIP 并解压，用浏览器打开 index.html 即可。页面包含完整数据快照，离线可查看；不用安装 Node.js、运行采集程序或连接平台账户。实际页面视觉验收由用户在设备完成，交付过程使用非浏览器检查。

## 部署到服务器

本仓库就是可交付静态站点，不需要原项目的本地档案。把 index.html 和 data-version.json 上传到 Nginx 网页目录即可；需要提供公开数据下载时同时上传 data 目录。也可以在静态托管平台选择无框架、不执行构建、输出目录为仓库根目录。

GitHub Pages 使用仓库内的自动部署流程；在 Settings → Pages 将部署来源设为 GitHub Actions。

## 更新与边界

当前网页采用构建时嵌入数据，浏览器刷新不会主动从远程服务器拉取新 JSON。更新数据时需要由私有构建环境生成新的 index.html，再连同新数据版本提交；单独替换 data 文件不会改变嵌入页面的快照。以后可再接入运行时远程数据读取。

数据格式版本为 1。当前快照 bd8842d73d037db6，来源日期分别保留在数据记录中，整理时间不代表重新采集。data/manifest.json 指向固定版本数据包，data/changes.json 记录变更。

缺报价、时长未知、优惠资格与素材时长等边界随数据保留。数据及页面尚未选择开放许可；平台与榜单第三方内容权利独立保留。
